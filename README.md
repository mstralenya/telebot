## Instagram Stories

Story links in the form `https://www.instagram.com/stories/<username>/<media-id>` are supported. Instagram normally requires an authenticated session to access Stories, so export Instagram cookies in Netscape format and set `INSTAGRAM_COOKIES_PATH` to that file. The bundled Compose configuration defaults to `/app/data/instagram-cookies.txt`.
